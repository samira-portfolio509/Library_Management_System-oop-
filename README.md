
# 📚 Library Management System (OOP Project)

এটি একটি জাভা-ভিত্তিক লাইব্রেরি ম্যানেজমেন্ট সিস্টেম যা **Object-Oriented Programming (OOP)** কনসেপ্ট ব্যবহার করে তৈরি করা হয়েছে।

## ✨ ফিচারসমূহ
- 📖 বইয়ের তালিকা ম্যানেজমেন্ট (যোগ করা, মুছে ফেলা, আপডেট করা)
- 🔍 বই খোঁজা (Search functionality)
- 👤 মেম্বারশিপ ম্যানেজমেন্ট
- 📑 বই ধার দেওয়া এবং ফেরত নেওয়ার হিসাব
- 💾 ডাটাবেজ বা ফাইল হ্যান্ডলিং (প্রজেক্ট অনুযায়ী)

## 🛠 টেকনোলজি স্ট্যাক
- **Language:** Java
- **Concepts:** Encapsulation, Inheritance, Polymorphism, Abstraction
- **Build Tool:** Maven/Gradle (Optional)

## 🚀 কীভাবে রান করবেন
১. প্রথমে রিপোজিটরি ক্লোন করুন:
   ```bash
   git clone https://github.com
   ```
২. আপনার ফেভারিট IDE-তে (IntelliJ IDEA/Eclipse/VS Code) প্রজেক্টটি ওপেন করুন।
৩. `Main.java` ফাইলটি রান করুন।

## 📁 ফাইল স্ট্রাকচার
- `src/`: সব সোর্স কোড (.java ফাইল) এখানে আছে।
- `.github/`: অটোমেটেড বিল্ড কনফিগারেশন।
